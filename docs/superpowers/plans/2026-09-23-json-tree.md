# Collapsible JSON viewer implementation plan

**Goal:** Default to root-level overview, let programmers inspect individual objects/arrays, prevent long input/output stretching the whole page, preserve full exact JSON copy.
**Architecture:** Add a token-preserving, iterative tree model and lazy DOM renderer in assets/json-tree.js. Existing formatJSON remains serialization authority; app keeps a complete output string separate from the rendered tree. Load tree module before app in both source and static builds. Native details/summary gives keyboard interaction; paginate sibling lists (100 per batch) and long scalar values. Input/output have bounded responsive heights and local scrolling.
**Scope:** Only JSON tool on production baseline 72cc1d8. Do not merge pending analytics branch. Prior session authorizes routine release. No backend, third-party scripts or persistence of input.
