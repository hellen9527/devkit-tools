# DevKit 访问统计方案

用户要求继续搜索平台配置，并配置GSC/GA4以了解真实访问。GSC保留用于Google搜索点击、展现、查询词和索引；Cloudflare用于请求/安全/性能；新增GA4用于同意统计的访问和工具操作。不同产品口径不同，不承诺总数一致或覆盖全部真人。

网站接入采用直接Google tag，避免增加Tag Manager。仅正式tools.fategenie.com启用，预览及404不启用。只在访问者选择允许后加载Google脚本（基本同意模式）；拒绝或未选择不发送请求。中英文提示、允许/拒绝同等入口，页脚可重新打开设置，撤回后停止后续统计。选择保存在本地，工具可不受影响地使用。

记录page_view和tool_action。操作事件只包含预定义tool_id/action/interface_language，不读取输入、输出、错误内容、搜索关键词或自由文本。工具按钮点击只称为操作，不称为成功转换。URL不发送query/hash；referrer只保留来源origin。GA4关闭增强型衡量、Google Signals及广告个性化，关闭可选账号数据共享。更新中英隐私说明，明确同意后由Google处理访问/设备/粗略地区与统计标识。

配置真实账号/媒体资源/数据流后取得G-衡量ID，保存在公开配置文件中（不是密钥），静态构建验证格式；未配置ID时不注入统计。用户已明确批准创建DevKit Analytics账号并继续流程；最终条款确认若出现必须单独展示并按浏览器规则确认。国家/时区已询问，以用户回答为准。

验收：未同意无脚本/无请求；同意仅一次pageview；刷新记忆；拒绝/撤回/存储被禁用；不捕获敏感工具数据；语言切换不重复计数；手机提示不遮挡操作；最终线上GA4实时收到测试访问。GSC关联在控制台权限允许时完成。
